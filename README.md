# Русские окна — новая главная страница

Новая главная для [rus-okna.ru](https://rus-okna.ru): пластиковые окна REHAU в Симферополе.

- `index.html`, `css/style.css`, `js/main.js` — вёрстка без сборки и зависимостей.
- `js/main.js` → массив `PROFILES`: цены и характеристики профилей (карточки, вкладки цен и калькулятор пересчитываются автоматически).
- `send.php` — отправка заявок и файлов сметы на почту менеджера (нужен хостинг с PHP; на GitHub Pages формы не отправляются).
- Чтобы добавить блок в «Решения для любых задач», скопируйте любой `<a class="solution">` в `index.html`.
